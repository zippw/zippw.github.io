FullStack Self-Hosted Open-Source

A lightweight PWA that turns any browser into a temporary file hub - no accounts, no cloud storage subscriptions, no USB cables. Drop files, share a 6-character vault ID or an invite link, and let others download (or upload) instantly. Just open, drop, and go. [PERSONAL USE ONLY]
